We now have the initial React Native + Expo + TypeScript + Expo Router project structure.

I want to build the first real feature: the Home screen for my food delivery app.

IMPORTANT:
I am learning React Native, so do not over-engineer this. Keep the implementation simple, readable, and beginner-friendly. Explain what you are doing and why.

## Goal

Build a polished but simple food delivery Home screen using local mock data only.

The Home screen should contain:

1. A header
   - Greeting such as "Good evening 👋"
   - Short subtitle such as "What are you craving today?"
   - A profile/avatar button on the right

2. A search bar
   - Search icon
   - Placeholder: "Search for restaurants or food"
   - It does not need to perform real searching yet

3. A horizontal food category list
   - Examples:
     - All
     - Burgers
     - Pizza
     - Chicken
     - African
     - Drinks
   - Each category should have a simple visual/icon or emoji
   - Make the category list horizontally scrollable
   - The selected category should have a different visual state
   - It does not need to actually filter restaurants yet

4. A "Popular near you" section
   - Display restaurant cards in a vertical list

5. Each restaurant card should contain:
   - Restaurant image
   - Restaurant name
   - Food category
   - Rating
   - Estimated delivery time
   - Delivery fee
   - Optional favorite/heart button

Example:

Restaurant: Chicken Republic
Category: Chicken • Fast Food
Rating: 4.6
Delivery: 25-35 min
Fee: ₦800

6. Add a "See all" button beside the Popular near you heading.
   - It does not need to do anything yet.

## Components

Create reusable components such as:

Put them in the components folder according to the project structure we created earlier.

The Home screen should mainly compose these components together.

Create a simple mock restaurant data file.

Use realistic Nigerian restaurant/food names and prices in Naira.
