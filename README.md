# Cravely 🍔

Your cravings, delivered.

A React Native food ordering app that lets users discover restaurants and fast food spots, browse menus, and place orders — with a clean, intuitive mobile experience.

## Overview

Cravely is a demo food-ordering app showcasing a complete mobile ordering flow — from discovery to checkout — built as my first full project in React Native.

## Features

- 🔐 Sign in / Sign up flow
- 🏠 Home screen with restaurant discovery, search, and category filters (Burgers, Pizza, Chicken, etc.)
- 🍽️ Restaurant details with full menu, pricing, and item ratings
- 🛒 Cart and order management
- ❤️ Favorites
- 👤 User profile with saved addresses and cards

## Tech Stack

- **React Native** — cross-platform mobile framework
- **Expo** — development and build tooling

## Getting Started

### Prerequisites

- Node.js installed
- Expo Go app (for testing on a physical device) or an Android/iOS simulator

### Installation

\`\`\`bash
# Clone the repository
git clone https://github.com/Opitien/cravely.git

# Navigate into the project
cd cravely

# Install dependencies
npm install

# Start the development server
npx expo start
\`\`\`

Scan the QR code with Expo Go, or run on a simulator (press `a` for Android, `i` for iOS).
